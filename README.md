# Carousel Studio – Privacy Policy

The privacy policy page for the Carousel Studio app (`index.html`), for hosting with GitHub Pages.

The text is the "No Tracking" privacy policy from the open-source
[App Privacy Policy Generator](https://app-privacy-policy-generator.nisrulz.com/)
([source](https://github.com/nisrulz/app-privacy-policy-generator)), for a mobile app, with its
template fields filled in. It is unchanged otherwise.

## Before publishing

Replace the highlighted placeholders in `index.html`:

- `[YOUR NAME]` – the developer or publisher name (as shown in the app stores)
- `[CONTACT EMAIL]` – the address for privacy questions (three places)
- `[EFFECTIVE DATE]` – the date the policy takes effect

Then remove the `.placeholder` highlight style if you like, make the repository public (or use a
plan that allows Pages on private repositories), and turn on Pages under Settings → Pages →
Deploy from a branch → `main` / root.
